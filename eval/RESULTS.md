# Retrieval eval results

Generated by `python eval/retrieval_eval.py`. See that script for methodology.

- **recall@5** — fraction of gold questions whose answer page is in the top-5 returned pages.
- **false-abstain** — fraction of on-topic questions that return nothing.

**Last measured: 2026-07-25**, against Token Saver 0.3.0.

> Superseded figures have been removed from this file. An earlier run
> (2026-07-09) recorded hybrid **0.97** / keyword-only **0.93**; those no longer
> reproduce and are not reported anywhere as current. §1.3 explains why, because
> the reason matters more than the numbers did.

## 1. Retrieval quality

### 1.1 Headline

| Metric | Hybrid (semantic + keyword) | Keyword-only |
|---|---|---|
| recall@5 | **0.90** (27/30) | **0.90** (27/30) |
| false-abstain | **0.00** | **0.00** |

SEM_FLOOR sweep, 0.15 → 0.35 in steps of 0.05:

```
SEM_FLOOR   recall@5   false-abstain
  0.15         0.90        0.00
  0.20         0.90        0.00
  0.25         0.90        0.00
  0.30         0.90        0.00
  0.35         0.90        0.00
```

Recall is flat across the whole range, so **SEM_FLOOR = 0.25 is a safe default
rather than a tuned one**. The gate is not the bottleneck at any tested value.

### 1.2 The two modes miss *different* questions

Hybrid and keyword-only both score 0.90, which looks like the semantic half is
contributing nothing. It is not — they fail on disjoint sets:

| document | question | hybrid | keyword |
|---|---|---|---|
| berkshire | "operating earnings reported for recent years" | **hit** | miss |
| berkshire | "does the company pay a dividend" | miss | **hit** |
| dobbs | "how does the opinion treat stare decisis" | **hit** | miss |
| dobbs | "Washington v. Glucksberg" | miss | **hit** |
| dobbs | "who gets to decide abortion policy after this ruling" | miss | miss |

Semantic uniquely rescues the two paraphrase-style questions; keyword uniquely
rescues the two hinging on an exact term ("dividend", a case name). The
aggregate tie hides real complementarity, which is the argument for keeping the
blend despite equal headline numbers.

The question missing in **both** is a pure paraphrase with essentially zero
content-word overlap with the holding's phrasing.

At 30 questions each worth 3.3 points, this eval cannot separate the two modes on
aggregate recall alone. That is a limitation of the gold set size, not a finding.

### 1.3 Why the earlier figures no longer reproduce

The corpus was verified **byte-identical** to the earlier run:

| doc | pages | sha256 (first 12) | matches pin |
|---|---|---|---|
| `berkshire.pdf` | 152 | `2132b85f9c47` | yes |
| `dobbs.pdf` | 213 | `24e1b14e521f` | yes |

Same questions, same bytes. The change is in **our code**, not the inputs:
query-side stop words, light stemming, and the eligibility gate all shipped
after the earlier run. The older numbers were real for the code as it stood then
and are not real for the code as it stands now.

This is recorded rather than quietly restated because a published number that
stops reproducing inside your own repository is worth knowing about.

## 3. Token savings

Measured with `tiktoken` (`cl100k_base`) on the shipped server path — one
question per document, whole extracted document vs. the chunks actually returned:

| document | pages | whole document | returned slice | saved |
|---|---|---|---|---|
| FDA drug label | 33 | 23,959 tok | 1,021 tok | **95.7%** |
| GDPR (EU 2016/679) | 88 | 70,260 tok | 996 tok | **98.6%** |
| *SFFA v. Harvard* | 233 | 133,349 tok | 740 tok | **99.4%** |

A separate degraded-mode run (no embeddings, page-mode keyword slices — the
worst case) measured **92%** across 3 questions on each of the two eval
documents. Read **92% as the floor** and the table above as the normal case.

**What the percentage does and does not mean.** Both sides use the same
tokenizer, so estimation error largely cancels in the ratio — the percentage is
the trustworthy quantity. The absolute token and dollar figures rest on a
modelling assumption: the naive baseline charges the **whole document on every
search**, and an unscoped search charges it for **every loaded document**. In
live sessions models issued 2–6 searches per question, so those totals are an
upper bound, not a measurement.

## 5. Cross-model end-to-end test (Claude Desktop)

Run against a **16-PDF personal folder** (court ruling, 10-K, shareholder letter,
ML papers, GDPR, drug label, two ~1000-page textbooks, marketing material) on
three models driving the same server: **Opus, Sonnet, Haiku**, same 10-prompt
script each.

### 5.1 What held

| Behaviour | Opus | Sonnet | Haiku |
|---|---|---|---|
| Page-cited answers from the local file | pass | pass | pass |
| Abstain on an absent topic ("crop rotation" in Apple's 10-K) | pass | pass | n/a |
| Disambiguation when 2 files match | pass | pass | auto-picked |
| Follow-up reuses the loaded doc | pass | pass | pass |
| Savings block relayed to the user | pass | pass | pass |
| Wrong-file recovery after correction | pass | pass | pass |

Citations were checked against the source: the Fourteenth Amendment answers
(pp. 4, 23, 27, 143) and the Munger tribute (p. 1) are correct in both
transcripts.

### 5.2 What broke — three defects, all fixed

**D1 — topic-only questions never reached the tool.** *"What did the Supreme
Court decide about affirmative action in college admissions?"* was answered by
Sonnet from **training knowledge** and by Haiku from a **web search**, with the
ruling sitting in the folder. Cause: the `ask` description was written entirely
around the user *naming* a file. Fixed by rewriting it around two explicit cases,
topic case first.

**D2 — the correct file was rejected by 0.006.** `berkshire-2023-letter.pdf`
scores **0.494** against a 0.50 filename bar for *"Warren Buffett's 2023 letter
to shareholders"* — right file, ranked first by 2.3×, discarded. Cost on Haiku:
**four** correction turns. Fixed with a near-miss rule (clear 0.35 *and* beat the
runner-up by 1.5×).

**D3 — the probe's rescue picked the wrong documents.** `_probe_text` read
metadata plus **page 1 only**; the Berkshire letter opens on the Munger tribute,
which contains neither "Buffett", "shareholder", nor "2023" — while "2023" *is*
on page 1 of the 10-K and the ruling. Fixed by probing 3 pages and requiring ≥2
distinct query-term matches.

### 5.3 Resolver accuracy on the real folder

14 references, before vs. after D2/D3 (`_resolve_document`, no model involved):

| | before | after |
|---|---|---|
| correct file | 8/14 | **12/14** |
| confident wrong file | 3/14 | **1/14** |
| correct "ask which one" | 1/14 | 1/14 |

The remaining false positive is **"pavlov's theory according to the textbook"**
→ the database-management textbook. Both books are ~1000 pages, "Pavlov" is in
neither's front matter, and "textbook" is in neither filename, so no
front-matter probe can separate them. Naming the subject (*"my psychology
textbook"*) resolves correctly. A genuine limit of front-matter probing,
recorded rather than papered over.

## 6. Known limitations (not fixed)

### 6.1 The abstain gate can false-accept

Query *"dragon husbandry and medieval falconry techniques"* against a 152-page
financial report returned **3 chunks** instead of abstaining. The keyword note
correctly flagged all four terms missing, but generic boilerplate still cleared
the cosine gate.

**Why the eval missed it:** the harness measures false-**abstain** (on-topic →
nothing), which is 0.00. It never measures false-**accept** (off-topic →
something). A large real corpus always has *some* chunk above the floor.

Full write-up, three candidate fixes, and why it is filed rather than patched:
[`docs/known-issues/false-accept-abstain-gate.md`](../docs/known-issues/false-accept-abstain-gate.md).
The short version: tightening the gate is exactly the change that could push
false-abstain off 0.00, so it needs a false-accept metric first.

### 6.2 Absolute savings figures are an upper bound

The baseline charges every loaded document on every search, and models issue 2–6
searches per question — one Haiku session reached a ~2.7M-token baseline across
36 searches. The **percentage** (92–99%) is consistent across all three models
and is the number to quote.

### 6.3 A page number is not a speaker label

For a document with a majority opinion plus dissents, both models had to infer
which side a passage came from; Haiku mislabelled a p154 dissent quote as the
majority's interpretation. The chunk envelope carries a page but no section
provenance.

## 7. Reproduce these numbers

```bash
python tests/mcp_selftest.py               # expect: RESULT: 106 passed, 0 failed
python tests/index_selftest.py             # expect: RESULT: 18 passed, 0 failed
python eval/retrieval_eval.py --download   # expect: recall@5 0.90, false-abstain 0.00
```

Optional cross-checks (after the `--download` above, which leaves the corpus in
`eval/corpus/`):

```bash
python eval/retrieval_eval.py --keyword-only --download
python eval/retrieval_eval.py --sweep-floor 0.15:0.35:0.05 --download
```

> If you see `recall@5 1.00 (10 gold questions)`, the real PDFs were not
> downloaded and you are scoring the built-in synthetic document only — not the
> published figure. The harness prints a loud warning when this happens.

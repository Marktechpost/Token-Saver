# Token Saver — server dependencies, for the DEVELOPER venv only.

# NOT an install path. Users install the .mcpb extension, and `uv` resolves the
# real dependency set from pyproject.toml inside the bundle. This file exists so
# scripts/install.sh can build a local .venv for the test suite; keep it in sync
# with [project.dependencies] in pyproject.toml.
#
# For a full developer checkout (the pdf_inspect table CLI and the
# token-measurement eval harness) install the complete set instead:
#     pip install -r requirements.txt
#
# pypdfium2 is optional: when present, index_store.py prefers it for higher-
# quality text extraction; if it is missing the code falls back to pypdf. It is
# included here because it is a small, torch-free wheel that improves accuracy.
